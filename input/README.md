
# University Course Registration System

## Project Description
A Java-based University Course Registration System.

## Concepts Used
- Object-Oriented Programming
- Inheritance
- Encapsulation
- Constructor Overloading
- Method Overloading
- Method Overriding
- Static Methods
- Exception Handling
- File Handling

## Classes
- Course
- LabCourse
- Main

## Custom Exceptions
- InvalidCreditsException
- InvalidFeeException
- InvalidLabHoursException
- InvalidScholarshipPercentException
- InvalidRecordException
- EmptyInputFileException

## Input File
input/courses.txt

## Output Files
- output/fee_statement.txt
- output/errors.txt

## How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Ensure the input folder contains courses.txt.
4. Run Main.java.
5. Check the output folder for generated reports.

## Programming Language
Java
